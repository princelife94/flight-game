Skyline Run — an original flight game. Fly a jet in chase view over a procedural island (sea, farmland valley, snowy ridge), through an 8-ring course and land on the runway. W/S throttle, arrow keys pitch/roll, mouse steers too; R restart, P pause, M mute.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open `out/game/index.html` in a desktop browser, or serve `game/` with any static server.
